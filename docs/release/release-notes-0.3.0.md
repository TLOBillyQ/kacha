# Kacha 0.3.0

本地 AI 图片生成与编辑客户端（画板版）。本版起 Windows 改为按当前用户安装的 NSIS 安装器，
内置官方自动更新：应用启动后自动检查新版，发现后在后台下载并验证签名，由用户主动点击
「重启并更新」后才安装；有未完成生成任务或画板保存未完成时不会安装，不自动重启。

## 本版变化

- **官方自动更新**：启动 3 秒后自动检查，运行期间每 6 小时检查一次；高级设置可手动检查。
- **后台下载、用户决定何时更新**：下载完成只提示就绪，不安装、不重启；更新包强制验证签名，
  损坏或被篡改的包不会进入安装。
- **更新前保护正在创作的内容**：排队、执行中或限流退避的生成任务阻止更新；点击更新时暂停
  新任务与画板修改，严格保存全部已打开画板与界面状态后才安装。
- **Windows 改为安装器分发**：按当前用户安装，通常无需管理员权限；首次从旧免安装版升级时
  手动安装一次新版，设置、画板、任务目录与生成结果位置不变。

## 下载

| 附件 | 适用平台 | 说明 |
| --- | --- | --- |
| `kacha-0.3.0-win-x64-setup.exe` | Windows 10 21H2+ / Windows 11（x64） | 当前用户安装器 |
| `SHA256SUMS` | — | 安装器与签名的 SHA-256 校验值 |

## 校验下载文件

把安装器与 `SHA256SUMS` 下载到同一目录后，在 PowerShell 执行，将输出与 `SHA256SUMS`
中对应行比较（大小写不敏感）：

```powershell
Get-FileHash -Algorithm SHA256 -Path .\kacha-0.3.0-win-x64-setup.exe
```

## Windows

1. 双击运行安装器，按当前用户安装，通常无需管理员权限。安装器会创建开始菜单与桌面快捷方式；
   升级时先关闭旧版本再安装，设置与画板不在程序目录里，不受影响。
2. **旧免安装版用户首次迁移**：关闭旧版本后运行本安装器完成一次安装，之后由自动更新接管；
   旧版 zip 目录可自行删除。
3. **SmartScreen**：本软件未购买代码签名证书，首次运行可能提示「Windows 已保护你的电脑 /
   未知发布者」，点「更多信息」→「仍要运行」。
4. **WebView2**：本应用依赖 Microsoft Edge WebView2 运行时，Windows 10 21H2 及以上与
   Windows 11 均已预装。若缺失，启动时会弹窗说明并给出官方下载地址。
5. **打开画板**：在应用内的画板列表中打开，或把 `.ugcboard.json` 文件拖到应用窗口 /
   `kacha.exe` 图标上。不支持双击画板文件打开（系统会把它当作普通 `.json` 文件）。

## 自动更新说明

- 更新服务器位于团队内网 Gitea，HTTP 仅限可信内网或 VPN 环境使用；更新包强制验证签名。
- 更新重启前会保存全部画板与界面状态；保存失败时不会安装，修复后可再次点击更新。
- 安装失败时界面会给出错误与手动下载入口，按上面的「Windows」一节手动安装即可，不会自动提权。
- 新版无法启动时，从 Release 页面下载旧版本安装器重新安装即可，数据不受影响；暂不支持自动回滚。

## 数据位置与问题反馈

- 设置与日志保存在系统的应用数据目录中（不在程序目录里），安装升级不会丢失。
- 遇到问题时，在应用「高级设置」底部点「导出诊断包…」，把导出的文件发给维护者。
  诊断包导出时会再做一次脱敏，不包含 API 密钥。
