# UGC AI 生图工具 0.2.0

本地 AI 图片生成与编辑客户端（画板版）。下载对应平台的压缩包，解压即用，无需安装。

## 本版变化

0.2.0 是 v2 的首个发布版本，客户端由 PySide6 重写为 Tauri + React Flow，与 v0.1.0 不兼容，需全新安装。

- **画板即主界面**：提示词、参考图、生成任务、结果都是画板上的节点，用连线表达「这次输入从哪儿来」，谱系一目了然；支持多画板标签页、框选 / 平移、撤销 / 重做、右键菜单与拖线建节点。
- **文生图与图片编辑**：生成任务节点按模型能力露出端口；参考图按「图N」序号接入，超出模型输入上限时发送前自动缩放 / 转码；单个干净任务运行时不再二次确认，可「查看发送文本」。
- **区域指示**：在参考图上框选一个或多个矩形，按「区域N」分色并在提示词中指代；叠加图由客户端自动生成随任务提交。
- **迭代动作**：以此继续编辑、加为参考图、生成变体，每一步都在画板上留下连线；结果列按时间累积，不覆盖旧结果。
- **图层拆分与透明背景**：支持的模型可把结果拆成带透明通道的图层，图层可单独作为后续输入。
- **模型**：上架 Seedream 5.0 pro / lite 与 qwen-image-3.0-pro / qwen-image-3.0，按旗舰 / 经济分档；负向提示词按模型能力自动分流。
- **画板包**：把画板连同引用的任务目录与图片导出为单个文件，在另一台机器上导入后继续工作。
- **任务目录为真源**：每个生成结果连同任务记录保存在本机任务目录中，画板只引用不持有；缺图时可重新定位。
- **高级设置与诊断**：网关地址、API 密钥、输出根目录、并发上限（默认 4）；「导出诊断包」自动脱敏，不含 API 密钥。
- **检查更新**：启动后静默向 Gitea 询问最新版本，有新版时顶栏出现「新版本」按钮，点开即下载；「高级设置」里也可手动检查。只提示不自动安装。
- **新应用图标**。

## 校验下载文件

把压缩包与 `SHA256SUMS` 下载到同一目录后核对。

Windows（PowerShell），将输出与 `SHA256SUMS` 中对应行比较（大小写不敏感）：

```powershell
Get-FileHash -Algorithm SHA256 -Path .\ugc-image-tool-0.2.0-win-x64.zip
```

macOS（终端，未下载的另一平台压缩包会报“文件不存在”，忽略即可）：

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing
```

## Windows

1. 解压 `ugc-image-tool-0.2.0-win-x64.zip` 到任意目录（可含中文路径），双击 `ugc-image-tool.exe` 运行。
   升级时关闭旧版本后直接用新 exe 覆盖即可，设置与日志不在程序目录里，不受影响。
2. **WebView2**：本应用依赖 Microsoft Edge WebView2 运行时，Windows 10 21H2 及以上与 Windows 11 均已预装。
   若机器上缺失，启动时会弹窗说明，并给出官方下载地址
   <https://developer.microsoft.com/microsoft-edge/webview2/>，安装「常青版运行时」后重新打开即可。
3. **SmartScreen**：本软件未做代码签名，首次运行可能提示“Windows 已保护你的电脑 / 未知发布者”，
   点「更多信息」→「仍要运行」。若压缩包是从浏览器下载的，也可以在解压前右键压缩包 →「属性」→
   勾选「解除锁定」→「确定」，再解压运行。
4. **打开画板**：在应用内的画板列表中打开，或把 `.ugcboard.json` 文件拖到应用窗口 / `ugc-image-tool.exe` 图标上。
   不支持双击画板文件打开（系统会把它当作普通 `.json` 文件）。

## macOS（仅 Apple Silicon）

1. 在「访达」中双击解压 `ugc-image-tool-0.2.0-macos-arm64.zip`，把 `UGC AI 生图工具.app` 拖入「应用程序」。
   Intel 芯片的 Mac 不受支持。
2. **Gatekeeper**：本软件仅 ad-hoc 签名、未经 Apple 公证，首次启动会被拦截。任选一种方式放行一次：
   - 在「应用程序」中右键（或按住 Control 点按）应用图标 →「打开」→ 在弹窗中再点「打开」；
   - 或先双击一次被拦截后，打开「系统设置」→「隐私与安全性」，在页面下方点「仍要打开」；
   - 或在终端执行：

     ```sh
     xattr -dr com.apple.quarantine "/Applications/UGC AI 生图工具.app"
     ```
3. **打开画板**：在应用内的画板列表中打开，或把 `.ugcboard.json` 文件拖到应用窗口 / 程序坞图标上。不支持双击画板文件打开。

## 数据位置与问题反馈

- 设置与日志保存在系统的应用数据目录中（不在程序目录里），覆盖升级不会丢失。
- 遇到问题时，在应用「高级设置」底部点「导出诊断包…」，把导出的文件发给维护者。
  诊断包导出时会再做一次脱敏，不包含 API 密钥。
