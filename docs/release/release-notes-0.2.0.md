# UGC AI 生图工具 0.2.0

本地 AI 图片生成与编辑客户端。下载对应平台的压缩包，解压即用，无需安装。
0.2.0 是全新重写的画板版，与 0.1.0 不兼容，请全新安装。

## 本版变化

- **画板即主界面**：提示词、参考图、生成任务、结果都是画板上的节点，用连线表达输入来源；支持多画板标签页、撤销 / 重做、右键菜单。
- **文生图与图片编辑**：参考图按「图N」接入，超出模型上限时自动缩放。
- **区域指示**：在参考图上框选矩形，在提示词里用「区域N」指代。
- **迭代动作**：以此继续编辑、加为参考图、生成变体，每一步都留在画板上。
- **图层拆分与透明背景**：支持的模型可把结果拆成带透明通道的图层。
- **新模型**：Seedream 5.0 pro / lite、qwen-image-3.0-pro / qwen-image-3.0。
- **画板包**：把画板连同图片导出为单个文件，换机器导入后继续工作。
- **检查更新**：有新版时顶栏出现「新版本」按钮，点开即下载。
- **新应用图标**。

## 下载

| 附件 | 适用平台 |
| --- | --- |
| `ugc-image-tool-0.2.0-win-x64.zip` | Windows 10 21H2+ / Windows 11（x64） |

| `SHA256SUMS` | 校验值 |

## Windows

1. 解压后双击 `ugc-image-tool.exe`。升级时关闭旧版本，用新 exe 覆盖即可。
2. 首次运行若提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
3. 若提示缺少 WebView2，到 <https://developer.microsoft.com/microsoft-edge/webview2/> 安装「常青版运行时」后重新打开。

## macOS

1. 解压后把 `UGC AI 生图工具.app` 拖入「应用程序」。不支持 Intel 芯片的 Mac。
2. 首次启动会被拦截：右键应用图标 →「打开」→ 再点「打开」；或在「系统设置 → 隐私与安全性」底部点「仍要打开」。

## 打开画板

在应用内的画板列表中打开，或把 `.ugcboard.json` 文件拖到应用窗口 / 应用图标上。不支持双击画板文件打开。

## 问题反馈

遇到问题时，在「高级设置」底部点「导出诊断包…」，把导出的文件发给维护者。诊断包不包含 API 密钥。
