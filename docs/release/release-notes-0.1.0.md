# UGC AI 生图工具 0.1.0 发布说明

面向蛋仔派对与千星 UGC 美术团队的本地图片生成工作台 **Windows x64 便携版**。

## 安全声明（必读）

- 客户端默认网关地址为**明文 HTTP**（`http://lzxsvn.com:3001`），因此
  API 密钥、提示词与参考图在传输层不加密。该默认地址**只允许**在隔离内网
  或可信 VPN 中使用。
- 网关一旦部署到非可信网络，发布前必须先通过“设置 → 团队网关基础地址”
  启用 **HTTPS 覆盖地址**后才能继续使用。收到更新提醒时请确认团队是否已
  切换 HTTPS 地址。
- API 密钥只保存在当前 Windows 用户的**系统凭据库**（服务名
  `ugc-image-tool`），不会进入设置文件、日志、任务记录或发布包。

## 安装与升级

- **无 Python 环境**：便携目录模式，解压后直接双击
  `ugc-image-tool.exe` 即可运行，无需安装 Python 或管理员权限。
- **首次使用**：解压 `ugc-image-tool-0.1.0-win-x64.zip`，建议解压到稳定
  目录；应用不在程序目录写入任何数据。
- **覆盖升级**：先关闭旧版本客户端，再用新版本压缩包**整体覆盖**程序
  目录（也可先删旧目录再解压新包）。设置、API 密钥、个人预设、生成结果与
  任务记录均位于用户目录或图片目录，不受覆盖升级影响。

## 功能摘要

- 文生图与图片编辑两个工作流，统一任务中心，并发上限 1～6。
- 通过团队网关实测的 Qwen 文生图与图片编辑模型；未知模型保持禁用。
- 内置（只读）与个人项目预设；个人预设保存在用户数据目录。
- 结果立即保存到本机图片目录，支持保存副本、复制到剪贴板与打开所在目录。
- 大小受限的轮转脱敏日志，可预览清单并导出诊断包。
- 仅简体中文界面。

## 校验值

发布包附带 `SHA256SUMS`（SHA-256）。核对方法（Windows PowerShell）：

    Get-FileHash -Algorithm SHA256 -Path ugc-image-tool-0.1.0-win-x64.zip

## 已知限制

- 默认明文 HTTP 仅限隔离内网或可信 VPN（见安全声明）。
- 关闭应用时不恢复未完成的任务队列；重启后只保留已落盘的
  结果与任务记录。
- 第一版不包含模型以外的视频生成与跨电脑同步。
