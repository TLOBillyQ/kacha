# UGC 美术工具模型矩阵

> 数据来源：千问 AI 平台 CLI 实时查询（2026-08-20）。价格为平台公示单价，团队 new-api 网关的实际计费策略以网关后台为准。
> 更新方式：`qianwen models list --output image --format json`、`qianwen models info <model-id> --format json`。

## 关键决策

### 1. 能力元数据内置，不依赖网关

new-api 的 `/v1/models` 只返回模型 ID，不提供编辑支持、分辨率上限、批量上限等能力信息。能力元数据必须内置在客户端（见 ADR 0004），用它过滤网关拉回的模型列表。矩阵中新引入的模型先通过 override 文件验证，再进入内置能力表。

### 2. 客户端不做成本预估

计费口径已分裂：`qwen-image-3.0` 系列按 token 计费，其余模型按张计费。客户端只展示单价口径，不估算单张成本，避免口径混乱误导使用者。

### 3. 备选链保证可用性

矩阵成立的前提是团队网关已开通对应模型并抹平端点差异。若某模型在网关上不可用，客户端按备选链降级。接入新模型前先对网关做冒烟测试。

## 特殊约束

- `z-image-turbo`：仅文生图，不进入图片编辑工作流，显示名固定为"快速写实文生图"（能力表强制约束）。
- `qwen-image-3.0-pro`：已进入内置能力表，文生图与图片编辑均可用。
- `qwen-image-2.0-pro`：支持 1–3 张输入参考图、1–6 张输出。
- `wan2.7-image-pro`：文生图最高 4K，编辑最高 2K。
