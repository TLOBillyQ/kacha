# 任务目录为真源，画板为视图

任务记录、参考图快照、结果图与派生图只存在于任务目录（`输出根目录/<UTC 日期>/<task_id>/`），提交后不可变；画板文件（`输出根目录/画板/<标题>.ugcboard.json`）只存节点、坐标、连线与脏判据快照，用相对路径 + `task_id` 引用任务目录，冗余的任务记录子集只供降级显示，冲突以 `task.json` 为准。删除画板、删除结果节点都不删任务目录。否决的候选是把图片与记录内嵌或搬进画板文件（画板自包含、可整体拷贝），理由是它会让同一张结果在多个画板间复制、脱离 v1 已有的任务目录追溯链，并把画板文件撑成 GB 级。代价是画板会遇到缺图：文件被移动或删除时节点保留占位、参与的任务不可运行，须由用户「重新定位」（只在输出根目录内按哈希 / `task_id` 找），切换输出根目录也不搬画板。详见 `docs/v2-spec.md` 第 9 节与 issue #59。
