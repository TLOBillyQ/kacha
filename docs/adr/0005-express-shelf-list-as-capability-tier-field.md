# 用能力表档位字段表达上架清单

客户端固定上架 qwen-image-3.0-pro（旗舰档）和 qwen-image-3.0（经济档），网关发现的其他模型不再出现在选择器中。上架清单不做成独立结构，而是能力表条目上的一个 `tier` 字段：有档位的条目即上架，无档位的模型（如实测中的新模型）保持隐藏。档位是纯客户端展示概念，不进网关协议，模型的行为差异仍全部由模型能力表达；两个页面的模型下拉框替换为「旗舰 | 经济」分段开关，持久化记住的是档位而非模型 ID，档内替换模型时用户无感。已提交的生成任务按任务记录中的模型继续执行，不受上架变化影响。

**Considered Options**：独立的上架清单文件被否决，因为清单与能力表是同一份知识的两个切面，拆开会产生"清单里有、能力表里没有"的不一致；完全写死两个模型、废弃网关发现被否决，因为它会推翻 ADR 0004 并给以后新增模型制造架构障碍。

**Consequences**：网关返回的未配置模型从 UI 彻底消失（此前显示为"未配置"禁用项）；新增模型仍需先通过网关契约实测再赋予档位，qwen-image-3.0 上架前必须补做实测；能力覆盖文件机制需要接线到生产代码，团队才能临时上架实测中的模型。
