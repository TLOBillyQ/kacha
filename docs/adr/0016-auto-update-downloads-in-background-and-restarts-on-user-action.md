# 自动更新后台下载，由用户主动执行更新重启

规格：[添加自动更新：迁移到 Tauri 官方 updater](https://github.com/TLOBillyQ/kacha/issues/3)。

应用启动 3 秒后检查一次，持续运行期间每 6 小时检查一次，高级设置提供手动检查。三种入口共享更新流程，合并并发检查；发现更高版本的正式版后后台下载并验证签名。下载完成只提示就绪，不安装，不重启。顶栏与高级设置展示同一版本、说明、进度和错误。

更新重启只能由用户点击触发。点击时读取最新全局任务队列，排队、执行中、限流退避及读取参考图阶段均阻止更新；任务结束不会自动重启，也不自动取消任务。

执行更新前暂停新生成任务、画板变更和界面状态变更，再确认任务队列为空。保护须覆盖已经开始的异步提交、导入和其他窗口事件。严格保存全部已打开画板与界面状态：立即处理保存计时器，等待进行中的写入，并重新保存此前失败的内容。普通关窗时吞掉保存错误的完成信号不能作为更新的成功依据。

任一安装前准备失败时，不安装、不重启，恢复正常操作并展示实际原因。官方安装期间维持保护，重复点击不能产生重复安装。安装失败提供可获取的错误与手动下载入口，不自动提权，不承诺插件无法观测的安装或启动结果。

后台检查或下载失败不弹窗打断创作，用户可手动重试。首版不提供断点续传、跨重启下载缓存、自动回滚、健康检查、强制更新、自动降级或预发布通道。应用标识、凭据标识、数据与输出位置保持不变。Windows 需要真实安装和更新验证；macOS 保留构建与脚本测试，不进行真机验收。
