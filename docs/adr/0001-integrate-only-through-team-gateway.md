# 第一版仅通过团队网关调用模型

第一版只集成团队的 new-api 网关，不提供千问原生接口作为备用通道。两套协议的端点、请求结构和响应结构差异明显，同时维护会扩大测试面；客户端将网关协议视为需要实测和固定的独立契约，而不假设它天然兼容 OpenAI 或千问原生接口。

2026-10-10 Flash 专属例外（[Issue #8 最终 Resolution](https://github.com/TLOBillyQ/kacha/issues/8#issuecomment-6093423192)）：`doubao-seedream-5-0-flash-260915` 的官方明确支持能力，在客户端实现及自动化验证完成后即可开放，不要求逐项等待网关实测。官方支持、团队网关实测、客户端实现分开记录；合成响应与脱敏夹具替代字节不构成新的真实网关或视觉证据。仍只调用团队网关；网关拒绝、坏响应或下载失败明确失败，不自动重发或换模型。未知协议保持未知，此例外不推广到其他模型。
