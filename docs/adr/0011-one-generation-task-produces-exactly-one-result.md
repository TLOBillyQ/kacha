# 一个生成任务恰产生一张生成结果

v2 取消出图数量：qwen 客户端固定向网关传 `n = 1`；Flash 普通模式按官方单结果契约，不发送 `n` 或 `sequential_image_generation`（包括 disabled），且返回必须恰好一张有效图片，多项/坏项均明确失败。Flash 图层拆分是同一原则下的专用形态：`data[]` 的底图与图层属于同一个生成结果（ADR 0010 的任务目录与 ADR 0013 的画板包语义不变），不把多项当成多张独立结果；任一图层失败即整体失败。一个生成任务恰产生一张生成结果，多张需求靠多次「重新生成」或「生成变体」，每次各成一个任务、各挂一个结果节点。网关对 qwen 系列实测支持 `n ≤ 5`（ADR 0006），所以这是有意放弃：一对一让结果节点与任务一一对应、结果列按时间累积、任务状态集无需「部分成功」、能力表无需出图数量维度，并与 Seedream 的组图（参考图数 + 生成数 ≤ 15，占参考图名额）划清界限。代价是批量出图变成多次提交、多个任务节点占位，以及 n > 1 时可能的单次计费优势不再可得（网关按张结算，差异主要在请求次数）。若日后重开多张出图，需新的能力表 `format_version` 加回字段，并重新裁定结果节点与任务的对应关系。详见原 v2 规格（已删除）第 3 节与 issue #55、#80。
