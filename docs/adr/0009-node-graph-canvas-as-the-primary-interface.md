# v2 主界面采用节点图画布范式

v2 的主界面是一张节点图画板：提示词、参考图、生成任务与生成结果各为一种节点，连线即派生关系，全图运行、结果自动挂到任务节点右侧的结果列。否决的候选有表单式（v1 现状，多轮修改后谱系不可见）、自由图片画布（Jaaz / Excalidraw 式，派生关系靠人记）、图层画布（InvokeAI / Krita 式，面向本地扩散模型的图层与 mask，与只走网关的指令式编辑模型不匹配）与对话式（网关不支持多轮消息，只能结果回灌，对话是假象）。选节点图的理由是：结果回灌路线下每一轮都是一次独立提交，只有连线能把「这张图从哪张改来」持续摆在美术眼前；代价是学习成本高于表单，以及所有交互约束（参考图上限、区域指示、换模型）都要在节点与端口上表达，由能力表驱动。详见原 v2 规格（已删除）第 3、4 节与 issue #55、#57。
