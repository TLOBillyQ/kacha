## 1. 目的地、原则与硬约束

**目的地**：UGC AI 生图工具 v2，主界面为节点图画板（提示词、参考图、生成任务、结果皆为节点，连线即派生关系），仍只经团队网关 new-api 提交，单机部署。绿地重构在本仓库内进行；v1 PySide6 客户端已从 main 移除，完整快照见 `archive/v1` 分支与标签 `v0.1.0`。

**裁决四原则**（细节争议按此裁）：贴合美术习惯的工作流、性能好、原生、轻量。

**保留的 ADR 与硬约束**：

## 2. 技术路线

- **壳**：Tauri 2（Rust 壳，Windows 用系统 WebView2，macOS 用 WKWebView）。
- **画布**：React Flow 12.x（TypeScript）。ComfyUI 不 fork（#67：去不掉 torch，前端重且随上游两周一版），只借设计：`@图N` 改写校验、参考图端口 Autogrow、声明式节点定义。
- **核心逻辑**：v1 约 8.4k 行 Python（网关调用、能力表、设置、结果落盘、脱敏）用 TypeScript 重写，落在前端；Rust 壳只承担日志器、凭据库、单实例、文件系统原子写与系统对话框。无 Python 运行时。
- **工具链**：正式 Windows 构建 MSVC（`x86_64-pc-windows-msvc`）；windows-gnu 只作应急备选。macOS arm64。
- **性能基线**（#63，Windows 真机，220 节点 / 200 张 512² 缩略图画板）：Tauri 线 130–135 FPS、首开 0.53–0.73 s、单 exe 3.2 MB、常驻内存 419 MB。macOS 数字进实施前补测。
- **单实例**：第二实例把命令行参数（含双击打开的画板文件路径）交给第一实例后退出；不用锁文件。
- 原型与数字：分支 `prototype/tech-route-63` @ 125958c，`prototype/README.md`。

## 3. 节点模型与连线

### 3.1 节点四型

| 节点 | 由谁创建 | 节点体 | 输入端口 | 输出端口 |
| --- | --- | --- | --- | --- |
| 提示词节点 | 用户 | 一段文本 | 无 | 文本，可扇出；接到正向或负向端口决定它这次的角色 |
| 参考图节点 | 用户（导入磁盘文件） | 缩略图 + 来源文件名 | 无 | 图片，可扇出 |
| 生成任务节点 | 用户 | 模型、生成尺寸（档位 + 比例两个下拉）、按能力露出的开关（拆分图层 / 透明背景） | 正向提示词（必接，至多一条）；负向提示词（可空，至多一条，模型不支持时不露出）；图片端口 Autogrow（上限 = 能力表参考图上限，每端口至多一条） | 结果，只由系统连线 |
| 结果节点 | 系统（任务成功后自动产出并连线） | 缩略图 + 任务记录快照子集（模型、提示词文本、尺寸、时间、任务编号）；透明角标、「N 图层」角标按文件推导 | 系统线 | 图片，可扇出，可接回任意生成任务节点图片端口 |

不设预设节点、工作流开关、出图数量。**出图数量整条取消，客户端固定传 1**；一个生成任务节点可多次提交，每次一个新任务、挂一个新结果节点。

### 3.2 连线合法性

- 提示词节点 → 生成任务节点正向 / 负向端口。
- 参考图节点、结果节点 → 生成任务节点图片端口。
- 生成任务节点 → 结果节点：系统自动建立，用户不可手连、不可手删；删结果节点即删线。
- 禁止成环；禁止跨画板连线（跨画板复用 = 在本画板新建参考图节点引用同一文件）；输入端口至多一条线；输出端口可扇出。
- 图片连线可选属性：`source_layer`（来源图层，空 = 底图）、区域指示（第 6 节）。

### 3.3 参考图序号

- **序号 = 用户图片端口自上而下的顺序**，用户可拖端口重排。这是用户在提示词里写的「图N」（**用户序号**），只数用户接的图片连线。
- 区域端口（第 6 节）不占用户序号：在节点上显示为从属于原图的「图1 · 叠加」锁定行，框选 / 删除区域、换模型导致区域端口长出或消失，都不改变用户序号（#113）。
- 实际发送顺序（**发送序号**）里叠加图紧跟原图；发送时客户端把用户的「图N」换算成发送序号（见第 5 节「图N」改写与校验）。
- 工作流由连线推导：图片端口 0 条线 = 文生图，≥1 条 = 图片编辑。

### 3.4 运行

- **全图运行**，不逐节点提交。范围：有选中节点时只跑选中子图，无选中时跑整个画板的脏任务。
- **总是二次确认**：弹窗列出将提交的任务（模型 + 提示词首行 + 完整发送文本可展开）与总数，N=1 也弹；清单带勾选框可临时剔除；标红的任务（第 10.4 节）列出原因且不可勾选。
- **脏判据**：上游提示词文本、图片端口集合（含来源图层、区域指示）、模型、尺寸、开关任一与 `last_submitted` 快照不同。运行时跳过不脏的已执行节点。
- 「重新生成」是任务节点上的显式动作，同参数重跑必得新图（无 seed），不由全图运行触发。

### 3.5 快照与上游编辑

- 提交即快照：提示词文本、参考图副本、区域参数在提交时读入内存，此后与上游节点脱钩；派发时固化进任务目录并写 `last_submitted`（排队中取消因此无痕，排队中异常退出不留记录）。
- 编辑一个已有下游执行记录的提示词节点时三选：**断开并分叉（默认）**：旧文本在原位新建提示词节点接旧任务，新文本留在被编辑节点；**不断开**：下游任务全部变脏；**取消编辑**。

## 4. 迭代动作与布局

三个迭代动作全部长在图片节点（结果节点 / 参考图节点）上；任务节点只有「重新生成」。

| 动作 | 触发于 | 图操作 | 提示词 / 参数 | 落位 |
| --- | --- | --- | --- | --- |
| 以此继续编辑 | 任一带图片输出的节点，支持多选 | 新建生成任务节点，触发节点图片输出接其图片端口，多选按选中顺序接入 | 新建**空**提示词节点接正向端口并聚焦；负向节点扇出复用源任务的；模型 / 尺寸继承源任务，源模型不支持编辑或触发于参考图节点时用工具栏模型（`last_model`；它也不支持编辑时用上架清单里第一个支持编辑的）；**不带区域指示** | 新任务在触发节点右侧，空提示词节点在其左上 |
| 加为参考图 | 结果节点 | 接到**恰好选中的一个**生成任务节点的下一个空图片端口；未选或多选时置灰并提示「先选一个生成任务」 | 不改参数；目标变脏 | 不新增节点 |
| 生成变体 | 结果节点 | 父任务同参数重跑（含开关、区域） | 不改 | 新结果进该任务结果列 |
| 派生连线 | 不变量 | 任一动作都留下可见连线；选中任一节点高亮上下游谱系 | — | — |

图层结果上，「加为参考图」「以此继续编辑」多一步「选底图 / 选某一图层」，从放大预览窗的图层侧栏发起（第 7 节）。

**布局**：流向左→右；任务节点右侧是结果列，结果按产出时间自上而下累积，新结果不覆盖不替换；自动落位只找就近空位，不推开、不重排，用户摆过的位置永远不动；复制任务节点走通用复制粘贴。

**删除**：删除不弹确认，靠撤销兜底（4.1）；结果节点被下游图片端口引用时允许删除并级联断开其下游连线，下游任务变脏，toast 说明断开条数；删任务节点级联删除其结果列（任务目录不动）；删排队 / 执行中的任务节点 = 先取消再删，这一步仍需确认，因为网关侧不可逆。

### 4.1 画板交互

**原则**：节点编辑器为体；采纳 PS 键位只当它在无限画布上仍成立、且不与主流节点编辑器（ComfyUI / Blender / Figma）冲突。画布上尽量只有图片，设置与记录不常驻节点内。术语见 `CONTEXT.md`（上下文菜单、拖线建节点、悬浮信息、悬浮动作条、精简节点、撤销步）。

| 主题 | 规则 |
| --- | --- |
| 精简节点 | 图片节点只显示图片、端口与角标（透明、图层数），可拖角等比缩放，尺寸存 `size`，默认宽 240px、最小 80px；缺图占位不变。任务节点只显示标题、状态徽标、模型名（只读）、端口行、运行按钮，标题栏箭头原地展开设置，展开态不存盘。提示词节点不精简。旧画板打开时不动位置与尺寸 |
| 悬浮信息 | 光标停留约 400ms 后在光标旁弹只读浮层，移出即消失，替换画布上全部原生 `title`（对话框不改）。内容：结果节点 = 模型、提示词全文（限 6 行）、尺寸、时间、任务号、透明 / 图层数、缺图原因；参考图节点 = 文件名与路径、像素尺寸、透明、警告原因；任务节点 = 模型、尺寸、不可运行原因、状态详情；提示词节点无；连线 = 区域数、来源图层；置灰动作 = 不可用原因 |
| 悬浮动作条 | 图片节点悬浮即显，固定屏幕像素、不随缩放（React Flow `NodeToolbar`），含放大预览、另存为与迭代动作；多选时选区上方只出一条，只含对多选有意义的动作 |
| 上下文菜单 | 一个框架。右键落在未选中节点上先换选区，落在选区内保持多选（多选菜单只给以此继续编辑 / 删除，右键点在结果节点上时另给加为参考图——先选任务再加选结果是它唯一可用的路径）。空白：新建提示词 / 新建生成任务 / 添加参考图… / 撤销 x / 重做 x，新节点左上角落在点击处；图片节点：放大预览 / 另存为…（新建不覆盖，重名加序号） / 以此继续编辑 / 加为参考图（结果） / 生成变体（结果） / 删除；任务节点：运行 / 取消 / 重新生成 / 展开设置 / 删除；提示词：删除；连线：断开 / 框选修改区域（图片线）。点菜单外、Esc、平移 / 缩放时关闭；不超出窗口边缘 |
| 拖线建节点 | 从端口拖线落空白：图片输出 → 等同「以此继续编辑」；提示词输出 → 新任务接正向；任务图片端口反向 → 添加参考图并接该端口。单候选松手即建，多候选弹上下文菜单；新节点落在松手处。拖线或拖入 OS 图片文件落在任务节点卡片上（非端口）= 接到下一个空图片端口（提示词接正向），OS 文件先建参考图节点；落在图片节点上无效 |
| 端口与连线 | 按类型着色：图片、正向提示词、负向提示词各一色，系统连线灰虚线；端口色 = 可接类型色，连线色 = 源端口色。端口 16px 圆点凸出边缘一半、热区 24px、悬浮节点时放大。空图片端口 = 虚线空心圆 +「拖图进来」，正向未接 = 红色空心圆 +「拖提示词进来」，接上后文字消失。拖线时合法目标端口放大发光，其余端口与节点降到约 35% 透明度。连线悬浮加粗提亮，选中显示中点 × 可断开；带区域指示的图片线在线上挂矩形徽标；形状贝塞尔 |
| 选中与谱系 | 选中 = 实线亮色描边 2px；谱系 = 柔和外发光，两者可叠加；选中时非谱系节点与连线降到约 35% 透明度，多选取并集 |
| 导航 | 左键拖空白 = 框选（相交即选）；右键拖、中键拖、空格 + 拖 = 平移，右键未拖动松手才弹上下文菜单（不设手形 / 选择模式切换）；滚轮 / Ctrl + 滚轮 / Alt + 滚轮 = 缩放，触控板双指 = 平移、捏合 = 缩放；Ctrl+0 适合全部、Ctrl+1 100%、Ctrl + = / − 步进；关闭双击缩放 |
| 选取与编辑键 | Shift + 点 / 框 = 加选；点空白或 Esc（无菜单 / 拖线时）= 清选区；连线可点选；Delete / Backspace 删除；Ctrl+C / V 复制粘贴，Ctrl+J 原地偏移复制，Alt + 拖复制；方向键微移 1px、Shift + 方向键 10px；焦点在可编辑元素上时画布快捷键一律不响应 |
| 新建任务模型 | 工具栏模型下拉 = 画板的 `last_model`，新建生成任务（菜单、拖线建节点）用它；是偏好不是画板编辑，不进撤销，撤销 / 重做保留当前值 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y，工具栏两个按钮带上一步描述。覆盖所有画板变更；一次拖动、一次删除、一次迭代动作、一段连续输入（停顿 500ms）、连按微移各为一步；文本框聚焦时交给原生撤销。系统写入（结果节点产出、`last_submitted`）不进历史、不清栈，撤销 / 重做时把晚于快照的结果节点及系统连线、锁定任务及其输入连线按当前状态合并回去。每画板独立、上限 100 步、仅内存（ADR 0012） |


## 5. 网关适配

- **多轮 = 结果回灌**：网关对 `input.messages` 只接受单条 user 消息（#71 实测 400）；Seedream 单次无状态（文档）。上一轮结果接回图片端口重提，不依赖任何会话参数。
- **「图N」改写与校验**（#69/#71）：用户提示词里 `@图N` → 中文提示词改写为「图N」，英文改写为 `Image N`；有区域叠加图时，`@图N`、不带 @ 的「图N」（前面是以「图」结尾的词时不算，如「地图2」「截图3」「示意图2」；「把图2」「放入图1」照常算）与 `Image N` 按用户序号 → 发送序号换算（例：图1 带区域时用户「图2」→ 发送「图3」），越界序号原样保留；数量顺序前缀与末尾固定句按发送序号生成，固定句在换算之后追加（#113）。沿用数量顺序前缀，按提示词语言：中文「本次提供 N 张参考图，按顺序为图1、图2…」，英文「This request provides N reference images, in order: Image 1, Image 2…」（与 `en_verified` 冒烟所用措辞一致）。编辑与连线时实时角标：按用户序号判断：引用序号 > 用户图片连线数 = 红，有线未被引用 = 黄（「算作引用」与换算同一口径；区域端口没有用户序号，不参与黄检查、也不能被引用；注入句按发送序号书写，换回用户序号后算引用）；二次确认弹窗红为硬阻断，黄仅警告。**绝不自动改写用户文本**。英文 `en_verified = 待测` 的模型仍改写为 `Image N`，二次确认提示「该模型英文序号未验证」。
- **qwen 系列请求**：沿 ADR 0006 与 `docs/contracts/team-gateway-contract.md`：文生图 `POST /v1/images/generations`；图片编辑 `POST /v1/images/edits` JSON，参考图 data-URL 按序进 `input.messages[0].content`，`parameters.size` 星号格式，`parameters.n` 固定 1，`fixed_params` 原样合并；出图真源 `metadata.output.choices[].message.content[].image`，兼容 URL 与 base64。
- **Seedream 系列请求**（#83 实测）：`POST /v1/images/generations`，顶层 `model` / `prompt` / `size` / `image`（data-URL 数组，按序即图N）/ `response_format:"url"` + `fixed_params`；出图在顶层 `data[].url`。qwen 的 `input.messages` 形态会被静默丢图，不可用。适配器按能力表 `request_shape` 分派。夹具 `contracts/fixtures/2026-09-17-team-gateway-seedream/`。
- **错误映射**：401 鉴权失败；429 限流（自动退避，第 8 节）；其他 4xx 网关拒绝；5xx 服务错误；网络不可达并入失败。不自动重发生成请求（429 除外），不用幂等键、不做任务查询、不依赖 `Retry-After`。
- 夹具：`contracts/fixtures/2026-08-17-team-gateway/`、`2026-08-29-team-gateway-edit-json/`、`2026-08-31-team-gateway-edit-boundaries/`、`2026-09-16-team-gateway-multiturn-refs-mask/`。

## 6. 区域指示

### 6.1 数据模型（三种渲染共用）

- 区域指示挂在**图片 → 生成任务图片端口那条连线**上，不是节点类型、不挂在图片节点上；同一张图扇出到两个任务可各有各的区域。
- 形状：矩形，一张图可多个；坐标归一化 0～1 浮点（相对原图宽高）。多边形留实施期备选，自由笔刷出界。
- 绘制：在放大预览窗里画，节点缩略图只回显。入口：任务节点图片端口悬停 / 右键「指示区域」直接绑定该线；从图片节点打开预览也能画，扇出 > 1 时先选目标任务。
- 连线打徽标；任务节点缩略图回显；结果节点预览可切换显示「本次编辑区域」轮廓，一律按**原图坐标**画，不显示派生图。
- 区域增删改 → 任务变脏。
- 只在能力表 `region_hint` 含「支持」取值时露出「指示区域」入口；待测 = 不露出。

### 6.2 三种渲染

| 渲染方式 | 发送形态 | 占名额 | 区域端口 | 注入 | 派生图 | 状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 高亮叠加参考图（qwen、Seedream 5.0 pro / lite；**当前唯一实现**） | 原图照发；叠加图作为紧随其后的一张参考图 | 占 1 | 自动长出、锁定，从属于原图、不占用户序号 | 末尾追加固定句（能力表模板，`{colors}` 填该图各区域颜色） | 叠加图：按区域编号分色（紫 RGB(128,0,255) / 黄 RGB(255,220,0) / 洋红 RGB(255,0,160)）50% 不透明，多矩形合成一张 | 已实测（#71；多区域分色 2026-09-17；Seedream 单 / 双区域 #83） |
| 图上标记（Seedream 5.0 pro / lite；暂不实现） | **标记图替换原图**发送 | 不占 | 无 | 末尾追加固定句，语义「只修改图N红框内的区域，其余保持不变」 | 标记图：红色 RGB(255,0,0) 实线矩形，线宽 = 短边 0.5%（最小 2 px），无箭头无文字，多矩形同一张 | 已实测单区域（#83）；双区域用紫 / 黄框亦 3/3 |
| 坐标标签（Seedream 5.0 pro；暂不实现） | 原图照发 | 不占 | 无 | 末尾追加一句「图N <bbox>x1 y1 x2 y2</bbox> 区域内按上述要求修改，其余保持不变」；多矩形同一句顿号并列，每个带「图N」；0～1 → 0～999 取 `round(v·999)`，保证 x1≤x2、y1≤y2；只用 `<bbox>` 不用 `<point>` | 无 | 已实测单 / 双区域（#83；lite 也命中但文档不支持，保守不开） |

- 画法与颜色是客户端常量，不进能力表、不开放配置（改了要重测）。
- 提示词节点文本不变；二次确认与任务快照记录完整发送文本。
- **区域编号**：一个任务内的区域按图片端口顺序、再按框选先后连续编号为区域1、区域2…，**上限 3 个**（超出标红不可运行）；每个编号固定一种颜色，预览框与节点缩略图按该色回显并标「区域N」。提示词里写「区域N」/ `Region N`，发送时改写为「紫色区域」/ `the purple region`（只改发送文本）；有区域时引用越界编号标红。同色多区域实测 0/3 对应正确（模型按阅读顺序猜），分色后 3/3。
- 模型同时支持多种时固定优先级 **高亮叠加 > 坐标标签 > 图上标记**，UI 不给切换。#83 双区域横向对比三种在 pro / lite 上均 3/3，准确率无差别，故选已实现且与 qwen 同一路径的高亮叠加（分色 +「区域N」改写直接复用）；Seedream 名额 10 / 14，占 1 个可接受。现有模型均支持高亮叠加，图上标记与坐标标签在实施期不实现，只保留能力表字段与本节规则，将来出现不支持高亮叠加的模型时再做。
- 超名额（含换模型导致上限下降）：连线保留、节点标红不可运行，二次确认列原因，绝不自动删线。
- 换模型跨渲染方式：区域端口长出或消失，只改变发送序号，用户序号不变；区域数据保留。

### 6.3 快照

任务记录 JSON 存：原图的发送序号 + 归一化矩形列表 + 渲染方式；`prompt` 存用户原文（用户序号），`send_text` 存换算后的实际发送文本。重新生成时按 `references[]` 顺序给非叠加条目编用户序号 1..k 还原对应关系，不新增字段。任务目录存派生图（叠加图 / 标记图），缺失可由参数重生成。

## 7. 图层拆分与透明背景

### 7.1 图层拆分（`layer_decomposition`，工作流级）

- 任务节点在该能力 = 支持时露出「拆分图层」开关；文生图与图片编辑各自露出。
- 仍产出**一个**结果节点；主文件为底图（合成整图），角标「N 图层」；图层是结果的内部结构，不是节点。
- 落盘：任务目录 `result.png` = 底图；图层 `layers/01.png…16.png` 按 `z_index` 升序编号；`z_index` / `bounding_box` 记进任务记录 JSON。画板结果节点多一个 `layer_count`；缺图按文件逐张走重新定位。
- 查看：放大预览窗加图层侧栏，缩略图按 `z_index` 排、勾选显隐叠加、点选单层看棋盘格透明预览。
- 接回作参考图：侧栏发起「选底图 / 选某一图层」，连线记 `source_layer`，谱系仍指向该结果节点；图层线可挂区域指示。
- 导出：保存底图 / 保存该图层 / 保存全部图层（文件夹：底图 + 序号图层 PNG + `layers.json` 含 `z_index` / `bounding_box`）。不做 PSD。
- 换模型：开关保留、节点标红不可运行；「生成变体」「重新生成」按快照原样重跑（含开关）。
- 状态：qwen 不支持；Seedream 5.0 pro 待测（#83 猜测参数均被忽略，官方参数形态未取得，入口不露出）；lite 不支持。

### 7.2 透明背景（`transparent_background`，模型级）

- 任务节点在该能力 = 支持、且**恰好一条**图片线、该图带 alpha 时露出「透明背景」开关；条件不满足时开关灰显并说明原因。
- 开关打开后再接第二条线 / 换成无 alpha 的图 / 换到不支持的模型：开关保留、节点标红不可运行，二次确认列原因，绝不自动关闭。
- 透明角标与棋盘格预览按文件是否带 alpha 推导，结果节点、参考图节点、图层统一规则。
- `output_format: png` 已在 Seedream 5.0 的 `fixed_params`。
- 请求映射：开关打开时 Seedream 5.0 pro 发送 `background:"transparent"`（#83 实测输出 RGBA；不带该参数输出白底 RGB）。
- 状态同 7.1。

### 7.3 出界

组图（`sequential_image_generation` 固定 `disabled`）、流式、联网搜索：不进节点图，能力表不留字段。多张需求走多次「重新生成」/「生成变体」。

## 8. 运行编排

- **任务节点即状态真相**：无任务中心、无运行面板。顶栏一个轻量**运行指示**（「执行 n · 排队 m」），点开小列表可跳到对应画板与节点，提供「取消全部排队」。
- **任务队列全局一条**，跨画板按提交顺序 FIFO。
- **并发上限**：高级设置全局项，默认 4，可调 1～10（qwen 实测 6～10 并发即 429，seedream 单模型 10 并发无 429；未补测，取经验值）；调到 6 以上时设置面板提示 qwen 曾在该并发下限流。
- **节点状态集**：排队中、执行中（旋转指示 + 已耗时）、失败（红徽标 + 脱敏错误类别，保留到下次提交）、已取消、已中断。成功不标，结果节点出现即成功；「结果未知」并入失败。状态只作徽标，不持久化到画板；失败 / 取消时在任务目录写结局记录 `outcome.json`（仅脱敏错误类别或取消标记），重开时有记录按记录显示、无记录（也无结果）推导为「已中断」。
- **取消**：排队中直接出队无痕；执行中只停本地等待，标「已取消」，不产生结果节点，文案「已取消本地等待，网关侧计算可能仍在继续」；429 退避中取消只标「已取消」（网关未接该请求），任务目录已写不删。
- **重试 = 重新生成**。唯一自动重试是 **429**：回队首，等 30 / 60 / 120 s，最多 3 次，节点显示「网关限流，N 秒后重试」，**退避期间整条队列暂停派发**，三次后按失败。401 / 其他 4xx / 5xx / 网络错误不自动重试。
- **运行期编辑**：排队 / 执行中的任务节点本体（模型、尺寸、开关、图片端口增删重排）与其连线锁定；上游提示词节点仍可编辑（走 3.5 三选）。
- **关闭画板 / 退出应用**仍有排队或执行中任务时阻断式二选一：「取消全部并关闭」或「留在画板」；无后台继续、不对账补结果；退出应用全局只弹一次。
- 异常退出后重开：进行中任务标「已中断」，可重新生成，不向网关追查。

## 9. 画板文件

**总原则：任务目录是真源，画板是视图**（ADR 0010）。任务目录 `输出根目录/<UTC 日期>/<task_id>/`（`task.json`、`reference-N.ext`、结果图、`layers/`、派生图，无结果时的结局记录 `outcome.json`）沿用 v1、不可变；画板只存图并引用任务目录；删画板永不删任务目录。

### 9.1 位置与命名

- `输出根目录/画板/<标题>.ugcboard.json`。标题存文件内，文件名由标题派生（去非法字符），重命名同步改文件名，重名加 ` (2)`，新建默认「未命名画板」。
- 切换输出根目录不搬文件：新根目录画板列表为空，旧画板留在旧根目录，设置面板提示一句。

### 9.2 格式与版本

- JSON 单文件，UTF-8，缩进；顶层整数 `format_version`（初值 1）。
- 只前向迁移；遇到更新的版本拒绝打开并提示升级、不改写文件；迁移成功时原文件先转 `.bak` 再写新版；未知字段读写保留。

### 9.3 结构

```jsonc

  "title": "未命名画板",
  "viewport": { "zoom": 1.0, "x": 0, "y": 0 },
```

- 节点 `id` 用 UUID；连线无独立 id；图片端口序号即 `image:<index>`；区域端口不落文件，由 `region` 推导。
- 图片身份：参考图 = 路径 + sha256（导入时算一次）；结果 = `task_id` + 文件名。
- **不存**：选中状态、运行状态、撤销栈。

### 9.4 缺图降级

- 结果引用相对路径为主，`task_id` 备用重定位；参考图记原路径 + 哈希，提交时才做快照。
- 缺图：节点保留、连线保留、不标脏；缩略图换占位 + 文件名 + 「重新定位」（选文件，或在输出根目录内按哈希 / `task_id` 搜，不扫全盘）。缺图节点参与的任务不可运行。

### 9.5 保存与恢复

- 每次图变更后去抖约 1 s 原子写；任务状态迁移立即写；无手动保存、无未保存标记。
- 写前保留一份 `.bak`；主文件损坏回退 `.bak` 并提示。
- 保存失败：内存不丢，画板顶部常驻红条「未能保存到 …」+「另存到…」，每次变更继续重试，不弹阻断对话框。
- 多画板标签页各自独立文件；界面状态记「上次打开列表 + 当前页」，启动恢复。
- 应用单实例，承接双击 `.ugcboard.json`。

## 10. 能力表

**原则：模型决定能力，能力决定生成任务节点上露出的端口、动作与可接类型。** 能力表是节点图 UI 的唯一约束来源，不按模型名猜。

### 10.1 载体

- 内置 JSON + 同 schema 的本地覆盖文件，顶层整数 `format_version`；覆盖文件按模型合并覆盖内置。
- 任务记录快照记 `format_version` + 生效表（内置 ∪ 覆盖）内容 sha256。

### 10.2 字段

**模型级**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `model_id`、`display_name` | string | |
| `tier` | 旗舰 / 经济 / 缺省 | 缺省 = 不上架（ADR 0005） |
| `help_url` | string | 官方文档链接，露出在任务节点模型说明浮层「查看官方文档」，系统浏览器打开；缺省不显示 |
| `request_shape` | enum | 网关请求形态；qwen = `/v1/images/edits` + `input.messages`；Seedream = `seedream_images_generations`（`/v1/images/generations` + 顶层 `image` 数组，#83） |
| `fixed_params` | 键值对 | 提交时原样合并进请求。qwen：`watermark:false`；Seedream 5.0：`watermark:false, output_format:"png"`；lite 另加 `sequential_image_generation:"disabled"`（#83 实测均生效 / 被接受） |
| `input_image_rule` | 对象 | 格式集合、最大字节、总像素范围、最短边、宽高比范围；连线 / 导入时预校验，违反在参考图节点标黄 |
| `reference_phrasing` | 对象 | 中文「图N」全模型通用；`en_verified` 三态（qwen、Seedream 5.0 pro / lite 均支持） |
| `region_hint` | 集合，每取值三态 | 取值 ∈ {高亮叠加参考图, 图上标记, 坐标标签}；占名额由取值推导（仅高亮叠加占 1）。qwen：高亮叠加 = 支持；Seedream pro：三种均支持；lite：高亮叠加、图上标记 = 支持，坐标标签 = 不支持（#83） |
| `region_hint_phrasing` | 取值 × {zh, en} 模板 | 固定句模板；qwen 措辞取 #71 夹具；Seedream 高亮叠加沿用 qwen 同一模板（#83 双区域 3/3）；图上标记 / 坐标标签暂不定模板 |
| `native_mask` | 三态 | 全部不支持 |
| `transparent_background` | 三态 | qwen 不支持；Seedream 5.0 pro 支持（`background:"transparent"`，#83）；lite 不支持 |

**工作流级**（`text_to_image` / `image_edit`，Seedream 单端点两个工作流填相同约束）

| 字段 | 说明 |
| --- | --- |
| `supports_negative_prompt` | qwen 支持；Seedream 全系不支持 → 负向端口不露出 |
| `min_references` / `max_references` | qwen 编辑 1–3；Seedream 5.0 pro 0–10、lite 0–14（#83 实测超限 HTTP 400）。Autogrow 上限 |
| `size_rule` | **档位 × 比例 → 像素**映射表 + 可选自定义像素区间（总像素、宽高比范围）。UI 统一「档位 + 比例」两个下拉，客户端换算为像素发送。qwen 现有预设归为 1K / 2K；Seedream 按官方映射表填 |
| `layer_decomposition` | 三态；qwen 不支持；Seedream 5.0 pro 待测；lite 不支持 |

**删除**：`min_images` / `max_images`（出图数量）、`extra_params`（改 `fixed_params`）、`sequential_generation` / `stream` / `web_search`。

### 10.3 三态

所有能力字段三态：支持 / 不支持 / 待测。**待测在 UI 上等同不支持**：动作与端口隐藏，仅在任务节点模型说明浮层列「待测」。模型选择器只按档位分组展示，不提示。

### 10.4 换模型规则

- 参考图连线超出新模型上限、负向端口在新模型不存在、图片线接到不支持编辑的模型、区域指示 / 开关在新模型不支持：**连线与设置保留、标红、节点不可运行**，二次确认列原因；绝不自动删线、绝不自动改设置。
- 区域指示动作只在 `region_hint` 含支持取值时露出。

### 10.5 初值与上架

- qwen-image-3.0-pro（旗舰）、qwen-image-3.0（经济）：按 v1 实测值上架。
- Seedream 5.0 pro（`doubao-seedream-5-0-pro-260628`）→ 旗舰、5.0 lite（`doubao-seedream-5-0-lite-260128`，网关不认正式 ID `-5-0-260128`）→ 经济，#83 通过已赋档位；提交链路待 #95 接入请求形态。4.5 / 4.0 已移除。
- `help_url` 初值：qwen 系列 https://platform.qianwenai.com/docs/developer-guides/image-generation/image-editing；Seedream 系列 https://docs.volcengine.com/docs/82379/1829186?lang=zh 。
- 资料：`docs/research/seedream-5.md`。

## 12. 高级设置、密钥、日志与诊断包

- **入口**：高级设置 = 主窗口内模态面板，覆盖画布，不开第二窗口；全部为全局项。诊断包导出入口在面板底部。
- **保留**：网关基础地址、API 密钥、连接测试（同时刷新模型发现）、输出根目录、并发上限（1～10 默认 4）、明文 HTTP 风险提示（ADR 0003）。
- **作废**：全局档位选择（模型在任务节点上选，新建任务默认 = 画板最近一次使用的模型，画板级记忆）；v1 表单记忆项全部。
- **文件**：Tauri app-data 目录，与 v1 `%LOCALAPPDATA%\ugc-image-tool` 分离、不迁移。`settings.json`（带 `format_version`，只前向迁移，更新版本拒开，损坏报错并用默认值）与 `ui-state.json`（窗口尺寸、上次打开画板、面板折叠；不迁移，损坏静默重置）分离。
- **密钥**：Rust `keyring` crate，Windows 凭据库 / macOS Keychain，服务名沿用 v1。凭据库不可用（含 Linux 无 secret service）只允许「本次会话内存保存」，界面标「未持久化，重启需重填」；永不明文落盘。
- **脱敏日志**：日志器由 Rust 壳持有，前端经单条 IPC `log_event(kind, fields)` 写入；轮转、容量（沿 v1）、脱敏集中在 Rust。事件集：v1 四类（任务迁移、连接、下载、系统）+ 画板保存失败、重新定位、429 退避（档位 + 整队暂停）、任务取消 / 已中断、队列派发。任务迁移事件带画板文件名 + 任务节点 id。提示词全文、图片、密钥不进日志。
- **诊断包**：默认含日志段、manifest、脱敏后的 `settings.json`（保留网关地址、无密钥）、能力表覆盖文件；画板文件与任务目录请求 / 响应 JSON 默认排除，清单预览中可勾选并标「含提示词」。导出二次脱敏、原子写 zip。

## 14. Seedream 实测结果（#83）

[网关冒烟复测：seedream 5.0 pro / lite](http://lzxsvn:3000/qinyuanj/ugc-image-tool/issues/83) 已于 2026-09-17 跑通，夹具 `contracts/fixtures/2026-09-17-team-gateway-seedream/`，合成几何图形、人眼核对：

1. `request_shape`：顶层 `image` 数组在 `/v1/images/generations` 与 `/v1/images/edits` 均生效，定为前者；`input.messages` 被静默丢弃。出图在顶层 `data[].url`。
2. 多轮：不可用，结果回灌。
3. `reference_phrasing.en_verified`：「图N」「Image N」「图一/二/三」3 张参考图下两模型各 6/6 → 支持。
4. `region_hint`：高亮叠加、图上标记两模型各 2/2；`<bbox>` pro 2/2、lite 2/2（lite 文档不支持，保守标不支持）；无指示对照未命中目标。

7. `max_references`：pro 10 / lite 14，超限 HTTP 400；并发 10 未触发 429（阈值未探）。
