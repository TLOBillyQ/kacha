# UI 重构设计规格：渐进式披露与极简界面

> **状态（2026-09-01）**：主体已由 issue #49–#52 实施落地（生成页双栏创作台、参考图披露、设置线性披露、任务中心语境操作）。仍开放：第 5 节记录的「新任务」提示触发偏差（见 6.2 遗留依赖）。本文档保留作为决议记录。

本文档汇编 [UI/UX 重构地图：渐进式披露与极简界面](http://lzxsvn:3000/qinyuanj/ugc-image-tool/issues/35) 全部已锁定决议，是可直接交付实施的设计规格。实施与走查不在本规格范围，另起实施地图。

- [生成页渐进式披露布局方案](http://lzxsvn:3000/qinyuanj/ugc-image-tool/issues/37)

术语遵循 `CONTEXT.md` 领域语言：**进阶选项**指生成任务中细化创作意图的可选输入（参考图、负向提示词、自定义宽高、出图数量），**高级设置**指影响客户端连接、执行与诊断的技术配置；两者不得混用。

约束前提：PySide6 桌面工具（Windows 10/11），轻量 Qt 样式表 + 系统原生控件；页面结构不动（「生成 / 设置」两个标签 + 任务中心右侧停靠面板）。

## 1. 通用约定

### 1.1 折叠组件模式

所有就地折叠区（生成页进阶选项、设置页「高级」分区）统一采用同一模式（#36）：

- **结构**：checkable `QToolButton`（箭头 + 文字）作为折叠头，控制内容容器 `setVisible()`。
- **动画**：默认不做展开动画。
- **样式**：折叠头最多一行 `QToolButton { border: none; }`。不再加其他样式——应用级样式表会破坏箭头绘制（QTBUG-44776/47507），且只设 background-color 不设 border 不生效。
- **可达性**：原生具备（聚焦后空格切换、`&` 助记符、无障碍切换状态）。
- **布局**：隐藏控件不占位，收起/展开零抖动。
- **反模式**：QToolBox（标签列手风琴）、QSplitter（拖拽压零）、min/max height 动画均为反模式，不得采用。
- 骨架代码与完整反模式清单见调研分支文档 `research/qt-disclosure-patterns` 的 `docs/research/qt-disclosure-patterns.md`。

### 1.2 折叠持久化行为

所有折叠区的展开状态按用户持久化，沿用现有先例：`SettingsStore` 布尔字段（现例：负向提示词勾选 `generation_negative_prompt_enabled`，`src/ugc_image_tool/settings.py`；用法先例 `src/ugc_image_tool/ui/pages/generate.py` 负向提示词勾选块）。

本规格新增/沿用的持久化位：

| 持久化位 | 内容 | 来源 |
| --- | --- | --- |
| 参考图区展开 | 生成页参考图折叠区展开状态 | #37 |
| 负向提示词展开 | 沿用现有勾选折叠语义（已输入内容保留） | #37（现状已有） |
| 出图数量展开 | 生成页右栏出图数量折叠行展开状态 | #37 |
| 「高级」分区展开 | 设置页高级折叠区展开状态 | #38 |
| 一次性提示已读 | 生成页进阶项一次性提示条消失标记，永不再现 | #47 |

### 1.3 样式 token 约定

原则：**复用 `src/ugc_image_tool/ui/presentation.py` 现有 token，不新增视觉体系。**

- 全部灰字（「高级」折叠态摘要、参考图空面板副文案、任务中心空态占位、一次性提示条文字等）用 `UI_TEXT_MUTED`。
- 明文 HTTP 风险提示文字用 `UI_ERROR`。
- 折叠头样式是唯一的组件级例外：仅 `QToolButton { border: none; }`（见 1.1），不引入折叠头专用 token。
- 唯一新增：一次性提示条的浅灰背景（#47 锁定形态为「灰底一行 + 关闭按钮」）。新增一个浅灰背景 token，取值在首次实施时选定（与 `UI_BORDER` 同一灰阶、明显更浅）并随即固定；这是本轮决议产生的唯一新 token。
- 原型分支上的试验性色值（如 `prototype/settings-advanced-38` 的卡片/警示框配色）不作为实施依据，仅作布局证据。

### 1.4 能力驱动的显隐

模型能力不支持的项目隐藏或禁用并说明原因（#37），不为不可用能力保留空入口。

## 2. 生成页（双栏创作台）

基线为去重后的 C「双栏创作台」（#37），空态与文案以已验证原型（`prototype/generate-progressive-disclosure` 分支，commit `02ef298`）为准。

### 2.1 默认态清单（首次打开可见）

| 位置 | 控件 |
| --- | --- |
| 主区 | 正向提示词（占位「描述画面、角色、风格与构图……」），占据主要创作空间 |
| 主区底部 | 「参考图（可选）」紧凑折叠入口行；负向提示词折叠入口行 |
| 主区 | 一次性提示条（未读时）：提示词下方、两个折叠入口之上，灰底一行「参考图与负向提示词收在这里，点开即用」+ 关闭按钮 |
| 右栏「本次生成」 | 项目预设选择（+ 单一「预设操作…」入口）、模型档位、生成尺寸（常用预设）、提交按钮 |

首次打开的基线形态：提示词为空、进阶选项全部收起、任务中心为空；模型档位、生成尺寸、出图数量沿用现有默认值（#47）。

**默认预设规则**（#47）：首次打开（无选择记录）时，若存在内置预设则默认选中并应用第一个内置预设（正、负提示词填入起点）；无内置预设则不选，落「选择项目预设」空态。不引入「默认预设」标记机制，哪一个居首由内置预设发布顺序决定。现状：`BUILTIN_PRESETS` 为空，空态是真实起点。

### 2.2 进阶态清单（折叠/按需出现）

| 进阶项 | 行为 |
| --- | --- |
| 参考图 | 点入口展开 1–3 张有序列表（空面板「＋ 添加参考图（可选，最多 3 张）」，副文案「拖放 PNG / JPEG 到这里；添加的参考图将用于图片编辑生成」，不写「自动转为图片编辑任务」这类机制描述）；添加即展开，清空后收回 |
| 负向提示词 | 就地披露（占位「输入不希望出现的内容」），沿用独立折叠与已输入内容保留语义 |
| 自定义宽高 | 不设独立入口；仅当生成尺寸选择「自定义…」时，宽高输入框在尺寸控件下就地出现 |
| 出图数量 | 右栏独立折叠行，默认收起 |

### 2.3 详细行为

- 参考图数量继续作为任务类型的唯一判据（有→图片编辑，无→文生图），不增加模式开关；预留 1–3 张以兼容 [多参考图开放试用](http://lzxsvn:3000/qinyuanj/ugc-image-tool/issues/34)。
- 项目预设的五个管理按钮（应用 / 复制 / 新建 / 编辑 / 删除）收敛为单一「预设操作…」入口，具体动作按当前预设类型提供，入口以 tooltip 说明内含动作。
- 右栏**不设**包含参考图、负向提示词或自定义尺寸的综合「更多参数」，避免与主区和尺寸选择重复（#37 明确排除）。
- 展开状态持久化见 1.2。

### 2.4 发现性策略（#47）

- 策略 = 入口行文案 + 一次性提示；不做欢迎页 / 教程页；占位提示只示范输入，不承担功能介绍。
- 一次性提示只覆盖参考图与负向提示词；点关闭按钮、或用户自行展开任一折叠区，均记为已读（SettingsStore 布尔位），永不再现。
- 出图数量、自定义宽高、预设操作不做额外引导：前两者靠入口行文案自解释（「出图数量」折叠行、尺寸下拉「自定义…」），「预设操作…」入口以 tooltip 说明。

## 3. 设置页（线性披露）

采用 A「线性披露」（#38）：输出目录 → 传输安全状态 → 「高级」折叠入口，自上而下线性排列，不引入卡片导航或双栏。

### 3.1 默认态清单

| 控件 | 行为 |
| --- | --- |
| 输出根目录 | 默认可见区唯一设置项，保持最常用操作的直接性 |
| 网关传输安全状态 | 固定位于输出根目录下方、折叠区之外，**折叠时仍然可见**（安全提示不属于高级设置）。明文 HTTP：红色风险提示（`UI_ERROR`）并提供「查看网关设置」动作；HTTPS：紧凑的安全状态提示 |
| 「高级」折叠入口 | 标题「高级」+ 折叠态灰字摘要「网关地址、API 密钥、连接测试、并发上限、本地诊断」（`UI_TEXT_MUTED`），不用 tooltip（#47） |

### 3.2 高级设置（默认折叠）

展开后按现有操作链线性排列，顺序固定：

1. 团队网关基础地址
2. API 密钥
3. 网关连接测试
4. 并发上限（**唯一入口**，任务中心不再有任何并发上限控件或只读值）
5. 本地诊断

展开状态持久化（1.2）。折叠头模式见 1.1。

## 4. 任务中心（收敛）

在不动 [任务中心停靠面板布局方案](http://lzxsvn:3000/qinyuanj/ugc-image-tool/issues/30) 停靠骨架（右侧停靠、预览优先竖排、停靠与召回行为）的前提下收敛（#39）。

### 4.1 移除项

- 移除任务中心的并发上限控件（含只读值）；唯一入口在设置页「高级」。

### 4.2 操作区规则

未选中生成任务时隐藏整个操作区；选中后按语境显示：

| 选中项状态 | 主操作 |
| --- | --- |
| 排队中 / 生成中 | 取消任务 |
| 生成结果可用 | 复制图片 |
| 失败 / 已取消 / 结果未知且无可用结果的终态 | 移除 |

**「更多」菜单**（省略号图标）：生成结果可用时提供「保存副本」「打开所在目录」；终态生成任务追加分隔线与「从任务中心移除」；无可用菜单项时隐藏「更多」。

**表达方式**：主操作用「图标 + 短文字」；主操作与「更多」均提供工具提示与无障碍名称。

### 4.3 语义约束

- 复制、保存副本、打开所在目录始终作用于当前选中的**单张**生成结果，不增加整项任务的批量结果操作。
- 仅终态生成任务可从任务中心移除；移除不删除磁盘结果，不增加二次确认。
- 空态：无任何生成任务时，停靠面板显示一行灰字占位「生成结果会出现在这里」（`UI_TEXT_MUTED`），不放按钮、不放教程（#47）。

## 5. 窗口框架与导航（边界确认，不改）

以下均不随本轮重构调整（#46）：

- 一级导航保持「生成 / 设置」两个标签页；不新增侧栏、主页、顶栏，不拆出文生图/图片编辑独立入口。
- 连接反馈：连接中与在线状态收在底部状态栏；缓存模型或离线时继续在标签页上方显示横幅，保留「前往设置检查连接」入口。
- 任务中心：右侧停靠面板、状态栏召回按钮、「面板隐藏时有新生成任务才显示新任务提示」的既有规格不变。
- 重构边界：渐进式披露只调整各页面内部默认可见控件，不改变窗口骨架。

**已知实现偏差**（记录在案，不在本地图修复）：当前实现在任意生成任务状态变化时触发「新任务」提示，而既有规格只针对新生成任务到达。
