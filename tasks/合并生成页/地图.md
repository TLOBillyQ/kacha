# 地图：合并文生图与图片编辑 UI

Labels: wayfinder:map

## Destination

以图片编辑为主，把文生图页与图片编辑页合并为一个生成页，直接在代码里落地（本地图携带执行，不止产出方案）。终点：主窗口只剩"生成"与"任务中心"两个标签，任务类型由有无参考图决定，旧文生图页删除。

## Notes

- 领域：PySide6 桌面应用（ugc_image_tool），Python；术语以根目录 CONTEXT.md 为准
- 每个会话应调用的技能：codebase-design、tdd、domain-modeling；grilling 票另加 grilling
- 本图为执行型地图：票可以解决决策，也可以直接落地改动，但一次会话只结一张票
- 本地 markdown 追踪器，无原生阻塞关系：票正文用 "Blocked by" 约定表达；开放票即子票，在此目录内按文件名查找

## Decisions so far

- [合并基线：八项已定决策](已定基线：合并的八项决策.md): 无模式开关、参考图数定类型、预设保留、状态收敛一份、标签名"生成"、旧值以编辑为准
- [合并执行路径与验收口径](合并执行路径与验收口径.md): 以图片编辑页为骨架演化单一「生成页」、删两旧页；提交判定落 generation 服务统一入口 submit_generate；设置收敛为一份（新键缺省回退 image_edit 旧值、弃用 text_to_image、不写迁移）；验收口径见票（类型边界/参考图禁用态/预设对编辑生效/旧值回退/校验兜底/结构验收）
- [合并页落地](合并页落地.md): 已实现并 verify 全绿（494 passed）：新增 GeneratePage 合并两页、删除 image_edit.py/text_to_image.py、submit_generate 统一入口、设置收敛一份、主窗口单一「生成」标签；验收口径 6 条全部由测试钉住。
