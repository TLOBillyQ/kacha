## Resolution

操作员答复 clar-20260831T041505125869Z「按你的推荐来，授权你」，5 项决策全部按推荐执行：

1. **演进路径**：以 image_edit.py 为骨架演化为单一「生成页」（类/文件改名 generate/GeneratePage）；无模式开关，参考图数量定任务类型（0→文生图，≥1→图片编辑）；预设区、无参考图提交路径并入；删除 image_edit.py 与 text_to_image.py 两旧页文件。
2. **text_to_image.py 与测试处置**：随迁项目预设整块（grouped_presets、应用/复制/新建/编辑/删除个人预设、update_prompt、prompt_values、mark_prompt_submitted、应用预设时未提交修改需确认）与 0 参考图提交路径；删除 text_to_image.py 整页与 test_text_to_image_ui.py 中只锚定旧页私有布局/命名控件的用例；保留 test_presets.py（测 preset store/应用层）；随迁行为用 Q5 验收用例写进生成页测试。
3. **提交判定落层**：generation 服务层统一入口 submit_generate(draft)，按 reference_paths 是否为空判定类型（有→图片编辑，无→文生图），构造对应 TextToImageRequest / ImageEditRequest 并给任务打 workflow；页面只收集草稿调用该入口，不再各自调 submit_text / submit_edit。
4. **设置层收敛**：AppSettings 的 selected_tier 与 negative_prompt_enabled 收敛为生成页一份（单一档位 + 单一负向勾选）；读取旧 settings.json 时新键缺失回退 image_edit 那份、弃用 text_to_image 那份，不写迁移代码（不重写文件，仅读取缺键回退）；Workflow 枚举保留两值仅供任务内部类型与各工作流校验复用。
5. **验收口径**：以类型判定边界、参考图禁用态、预设对编辑任务生效、设置读取回退、提交校验兜底、结构验收（单一「生成」标签，删除两页类，设置页与任务中心保留）为合并完成的测试门槛，须被单元测试钉住。
