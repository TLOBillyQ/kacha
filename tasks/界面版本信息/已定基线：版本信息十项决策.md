# 版本信息基线：十项已定决策

Labels: wayfinder:grilling
Status: closed（建图会话中由用户逐轮确认，2026-09-01）
Assignee: SwarmForge

## Question

在编辑器界面显示软件版本信息：给谁看、放哪、显示什么、版本号与 commit hash 从哪里来、
dev 与打包构建各自如何取值、顺手处理哪些版本来源问题。

## Resolution

用户在 grilling 会话的四轮问答中逐项确认：

1. **用途**：报障/客服场景，用户截图时天然带出版本，不做「自查最新版」功能
2. **范围**：全局常驻，不是只加在生成页；落点在主窗口（QTabWidget 各页与任务中心 dock 自动覆盖）
3. **形态**：主窗口**状态栏右侧**永久角标，不做关于弹窗、浮动覆盖层，不进窗口标题
4. **内容**：语义化版本号 + commit 短 hash，形如 `v0.1.0 (a1b2c3d)`
5. **更新提醒**：本期不做（查 Gitea 最新版是独立功能，另行立项）
6. **可点击复制**：点击角标复制**所见即所得**的版本串（所见即所贴），tooltip 提示「点击复制」；不加构建时间等额外字段
7. **dev 构建**：显示 `v0.1.0-dev (a1b2c3d, dirty)`；git 不可用时只显示版本 + `-dev`
8. **hash 来源**：打包时把 `release/build-info.json` 作为 PyInstaller 数据文件进包，运行时读取；dev 下运行时 `git rev-parse --short HEAD` 回退
9. **spec 回退**：`packaging/ugc-image-tool.spec` 中 `UGC_IMAGE_TOOL_VERSION` 未注入时由静默回退 `0.1.0` 改为**构建失败**，杜绝界面显示假版本
10. **工程要求**：版本串组装抽纯函数 + pytest 单测

## 补充事实（已查代码确认）

- PySide6 桌面应用（ADR 0002），无 web 层；主窗口 `ui/main_window.py`（QTabWidget：生成 + 设置）
- **界面上当前无任何版本显示**；状态栏只有连接状态点和消息文本
- 版本权威来源 `pyproject.toml`（ADR 0007），运行时读 `diagnostics.app_version()`（importlib.metadata 链）
- commit hash 目前只写进 `release/build-info.json`（发布用），**不进入应用本体**
- 版本串现存 3 处副本：pyproject、`__init__.py:__version__`、spec 硬编码回退，无同步校验
- `__init__.py` 的 `__version__` 动态化收敛**本期不做**（另 PR）
- 设置页**不加关于区**（角标是唯一展示位；将来做更新检查时再说）
