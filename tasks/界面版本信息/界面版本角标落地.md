# 界面版本角标落地

Labels: wayfinder:task
Status: open
Assignee: coder

## Question

按已批准方案在界面落地版本信息角标。决策已定（见 [已定基线：版本信息十项决策](已定基线：版本信息十项决策.md)）：

- 主窗口状态栏右侧永久角标，形如 `v0.1.0 (a1b2c3d)`；点击复制所见即所得的版本串，tooltip「点击复制」
- 版本号走 `diagnostics.app_version()`（importlib.metadata → pyproject，ADR 0007 唯一来源）
- commit hash：打包时把 `release/build-info.json` 作为 PyInstaller 数据文件进包，运行时读取；dev 下 `git rev-parse --short HEAD` 回退，显示 `v0.1.0-dev (a1b2c3d, dirty)`，git 不可用则仅版本 + `-dev`
- `packaging/ugc-image-tool.spec`：`UGC_IMAGE_TOOL_VERSION` 未注入时构建失败，不再静默回退 `0.1.0`
- 不做：更新提醒、设置页关于区、关于弹窗、浮动覆盖层、`__version__` 动态化

产出：绿色单元测试 + 实现（按 coder 角色以 TDD 逐步落地）。版本串组装抽纯函数放 `diagnostics.py`（或独立小模块），UI 层只消费结果。

验收口径（测试门槛）：

1. **版本串组装分支**：hash 有/无、dev/dirty、git 不可用回退，各分支输出符合基线第 4、7 条
2. **打包产物自检**：spec 未注入 `UGC_IMAGE_TOOL_VERSION` 时构建失败（断言逻辑可用最小脚本测试，无需真跑 PyInstaller 全量构建）
3. **角标行为**：状态栏存在版本标签、文本与纯函数输出一致、点击后剪贴板内容与显示文本完全一致
4. `python tools/cli.py verify` 全绿
