# Kacha（咔嚓）

📸 咔嚓一下，图就来了。

面向蛋仔派对与千星 UGC 美术团队的本地图片生成工作台。以节点图画板为主界面：提示词、参考图、生成任务、结果都是画板上的节点，连线表达「这次输入从哪儿来」。生成只经团队网关提交，结果保存在本机。

![画板界面：「千问测试」画板包，一条图片编辑迭代链，谱系连线可追溯](docs/screenshots/app-canvas.png)

## 下载与安装

到 [Gitea Releases](http://lzxsvn:3000/qinyuanj/kacha/releases) 下载对应平台的附件。Windows `v0.3.0`（2026-10-09）是首个带 updater 签名的正式版，真实端点下载与 updater 签名已验证，用户已反馈一次真实更新成功；队列 / 保存保护、故障恢复与旧版迁移的完整验收仍在进行。macOS 正式版尚未发布。已有旧版附件按对应版本发布说明使用。

带 updater 签名的正式版使用以下分发格式（macOS 附件尚未发布）：

| 附件 | 适用平台 |
| --- | --- |
| `kacha-<版本>-win-x64-setup.exe` | Windows 10 21H2+ / Windows 11（x64），NSIS 按当前用户安装，依赖 WebView2 |
| `kacha-<版本>-macos-arm64.zip` | macOS，仅 Apple Silicon，首次手动替换 `Kacha.app` 到 `/Applications` |

Updater 签名独立于操作系统代码签名。Windows 没有购买代码签名证书，首次安装或运行可能需要在 SmartScreen 点「更多信息 → 仍要运行」；macOS 仅 ad-hoc 签名、未经 Apple 公证，首次需要 Gatekeeper 放行。macOS 真机安装、迁移与自动更新**未验收**。

旧 Windows 免安装版需要手动安装一次；迁移沿用同一用户的数据、系统凭据和输出根目录。首次使用在「高级设置」填团队网关地址与 API 密钥。现有 HTTP Gitea 与网关仅用于可信内网或 VPN，不提供传输加密。

安装迁移、更新状态及故障恢复见 [自动更新用户指南](docs/release/auto-update-user-guide.md)；已验证事实与待补证据见 [Windows 自动更新验收记录](docs/release/auto-update-windows-acceptance.md)。

## 主要功能

- **画板**：多画板标签页、框选 / 平移、撤销 / 重做、右键菜单、拖线建节点。
- **文生图与图片编辑**：生成任务节点按模型能力露出端口，参考图按 `图N` 接入；超出模型输入上限时自动缩放。
- **区域指示**：在参考图上框选矩形，按 `区域N` 分色并在提示词里指代。
- **迭代动作**：以此继续编辑、加为参考图、生成变体，每一步都留下连线，谱系可追溯。
- **透明背景（Flash）**：在生成任务的进阶选项开启，仅允许一张已确认带透明像素的实际参考图，输出选择 PNG。无图、多图、alpha 未知、JPEG 输出或高亮叠加后变成两张输入时会阻止运行；来源图层按所选图层文件校验。关闭开关使用默认 opaque。重新生成沿用任务目录中的开关、输出格式和参考图快照；网关拒绝或下载失败明确报错，不自动换模型或重发。
- **图层拆分（Flash）**：支持的模型可把结果拆为带透明通道的独立图层。预览弹窗里可整体导出：底图 + layers/ 子目录下的图层文件 + layers.json（含各层名称 / 描述、层序、absolute 像素与 normalized 0–1000 定位）；图层可直接「加为参考图 / 以此继续编辑」，发送的是该图层的实际字节，谱系仍指向产出它的结果；图层文件缺失或来源图层身份无效会明确阻止运行，不回落到底图。换机重开按任务目录里的 layers.json 真源还原图层。
- **画板包**：把画板连同引用的任务目录（含图层文件与 layers.json）打成单个文件，换机器导入后继续工作；导出前列出缺失的图片与图层文件。
- **诊断包**：一键导出脱敏日志与设置，不含 API 密钥。
- **自动更新**：自动检查并后台下载更高版本的正式版，展示进度与更新说明；由用户点击「重启并更新」，任务队列为空且全部已打开画板与界面状态保存成功后才安装。Windows 自 `v0.3.0` 起经 updater 签名正式发布；macOS 更新包随首个 macOS 正式版提供。

内置模型：Seedream 5.0 pro / Flash、qwen-image-3.0-pro / qwen-image-3.0。Flash（`doubao-seedream-5-0-flash-260915`）接替经济档，并作为新建生成任务的首选；画板最近明确选择的其它模型仍上架且网关可用时继续优先。模型发现缓存按网关地址隔离，缓存缺少 Flash 时先刷新；仍缺失或刷新失败时显示 Flash 不可用，不自动选择其它模型。用户可手动选择可用模型，再按其能力检查参数。

Lite 已停用。旧画板及导入的画板包仍可查看，旧节点、生成结果与任务目录中的原始模型身份保持不变；不会自动迁移、转换参数或删减参考图。普通运行、旧任务的重新生成、旧结果的生成变体，以及继承 Lite 的继续编辑后续生成，都会提示「Lite 已停用，请切换到 Flash」。请在生成任务节点中手动选择 Flash，按其分辨率档和参考图限制调整参数，再点「运行」创建新任务。修改当前节点后，旧任务的「重新生成」和旧结果的「生成变体」仍读取历史 Lite 身份并阻止；旧结果仍可作为其它模型的参考图。
